# 책 설정 (이 파일만 채우면 스킬이 작동한다)

> 아래 항목을 실제 값으로 채워 넣으세요. 다른 책(다음 학기, 다른 코스웍 모음)을 또 묶을 때도 이 파일만 새로 채우면 됩니다.

## 기본 정보

- 제목: (예: "정치철학 세미나 단상: 2026년 박사과정 코스웍 에세이 모음")
- 부제: (선택)
- 저자명: (실명. 학술서이므로 필명 대신 실명을 기본으로 한다)
- 소속: (예: OO대학교 대학원 OO학과 박사과정)
- 지도교수/세미나 담당교수: (선택, 감사의 글에 쓰일 수 있음)
- 대상 독자: (예: 같은 분야 대학원생, 지도교수, 학계 동료 / 또는 "일반 교양 독자도 읽을 수 있게")
- 목표 분량: (예: 200~250페이지, 약 100,000~130,000자)
- 기준 연도: (예: 2026년. 에세이 내 "올해", "최근" 같은 표현을 통일할 때 기준)

## 원본 위치

- 에세이 원본 폴더: (예: `essays/`. `/collect` 단계가 이 경로를 최우선으로 찾는다)
- 파일명 규칙: (예: `YYYYMMDD_주제.md`, 또는 "파일명에 규칙 없음, 폴더 안 전체를 스캔")

## 인용 스타일

- 서지 인용 방식: (APA / Chicago (저자-연도) / Chicago (각주) / MLA / 학과 자체 양식 - 하나를 선택)
- 참고문헌 정렬 기준: (저자명 가나다/알파벳순 등)
- 각주 사용 여부: (예/아니오 - "예"면 `/publish` 단계에서 Word 각주 삽입 방식을 확인해야 한다. 자동화가 어려우면 장 끝 미주로 대체할 수 있다)

- 코스웍 에세이를 단행본으로 재구성하며 바뀐 점(연결 문단 추가 등)을 독자에게 밝힌다

### 제1부: (주제명)
- 제1장: (에세이 주제 - 실제 에세이 파일과 매핑은 /organize 단계에서 확정)
- 제2장: ...

### 제2부: (주제명)
- ...

### 결론
- 코스웍 전체를 관통하는 문제의식 정리
- 후속 연구 방향 (있다면)

### 참고문헌
- 모든 장의 인용을 통합하여 하나의 서지 목록으로 정렬

### 부록 (선택)

- (예시) "행위자성" / "에이전시" 혼용 → "행위자성"으로 통일

## 검증 규칙

이 섹션은 자동 검사기(`scripts/verify.py`)가 그대로 읽어 검사 기준으로 쓴다. 값을 바꾸면 이 책에 맞게 검사가 바뀐다. 이 섹션을 통째로 지우면 검사기는 기본값(해라체, em dash 비허용 등)으로 동작한다.

- 어미: 해라체 (한국어 학술 논문 관행. 존댓말 책이면 "합쇼체"로 변경)
- em dash 허용: 아니오
- 불릿 기호: •
- 금지 용어: (예: "행위자성 → 에이전시" 처럼 통일 방향과 반대로 쓰인 경우를 잡고 싶으면 여기에)
- 금지 영어 표현: (예: 없음. 학술서는 영어 병기가 필요할 수 있으므로 기본은 비워둔다)
- 장 연결 문단 필수 문구: (예: 없음. 트레이드북과 달리 "N부를 마치며" 같은 고정 문구를 강제하지 않는다. 필요하면 채운다)

작성 요령은 `scripts/verify.py` 상단 주석을 참고한다.

## 퍼블리싱 사양

### 본문 스타일
- 본문 폰트: (예: 신명조 11pt, 줄간격 1.5 - 학술서 관행에 맞게)
- 부/장 제목 스타일: (폰트, 크기, 색상 - 학술서는 보통 흑백 단색 권장)
- 페이지 여백: (예: 상하좌우 2.5~3cm)
- 인용문(블록 인용) 서식: (들여쓰기, 폰트 크기 축소 등 학술서 관행)

### 문서 구성 요소
- 표지: 기본 텍스트 레이아웃. 제목, 부제, 저자명, 소속
- 목차, 페이지 번호, 헤더/푸터
- 참고문헌 (책 끝에 통합)
- 부록 (선택)

### 시각 자료
- 이 책은 원칙적으로 에세이 원문 기반이므로 이미지를 새로 창작하지 않는다. 원 에세이에 있던 표/그림만 그대로 옮긴다
