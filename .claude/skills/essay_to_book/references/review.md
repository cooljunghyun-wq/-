트레이드북용 9인 앙상블 리뷰(book_publishing 스킬)와 달리, 학술 단행본이고 최소 편집이 원칙이므로 리뷰어를 4인으로 줄인다. 각 리뷰어는 **동일 원고를 각자의 관점으로 독립 채점**한다.

```bash

echo "활성 프로젝트 폴더: ${ACTIVE}"
```

## 공통 규칙

### 심각도 분류

| 심각도 | 의미 | 처리 |
|--------|------|------|
| 🔴 필수 | 기계적 오류. 오탈자, 인용 형식 불일치, 목차 항목 누락, 장 연결 누락 | 자동 반영 |
| 🟡 권장 | 논지·근거·표현에 관한 의견 | **반영하지 않음.** `pending-suggestions.md`로 사용자에게 보고 |
| 🟢 참고 | 사소한 스타일 선호 | 무시 가능, 원하면 보고에만 포함 |

🔴와 🟡의 경계가 "이 수정이 저자의 원래 의미를 바꾸는가"이다. 의미가 바뀌면 아무리 사소해 보여도 🟡 이하로 분류한다.

### 지적 사항 출력 형식

```
[심각도] [위치] - [제목]
- 원문: "..." (있으면 정확히 인용)
- 문제점: 구체적으로 무엇이 문제인가
- 수정 제안: 어떻게 고치면 좋은가 (🔴는 실제로 반영할 수정, 🟡/🟢는 제안일 뿐)
```

```

04_review-coherence 있음, 04_review-rigor 없음                → 3단계(학술 엄밀성)부터
04_review-rigor 있음, 04_review-minimal-edit 없음             → 4단계(최소편집 준수)부터

```

## 1단계: 교정 리뷰 (Proofreader)

### 역할
20년차 교정교열 전문가. 감정 없이 사실만 지적한다. 어휘·맞춤법·부호·인용 형식 일관성을 본다.

### 입력 / 출력
- 입력: `{ACTIVE}/03_manuscript-v1.md`
- 출력: `{ACTIVE}/04_review-proofreader.md`

### 평가 항목

| 항목 | 🔴 기준 | 🟡 기준 |
|------|---------|---------|
| 맞춤법/오타 | 표준국어대사전 기준 명백한 오류 | 띄어쓰기 스타일 차이 |
| 비문 | 주어-술어 호응 깨짐 | 문장이 길어 의미가 흐려짐 |
| 인용 형식 | book-config 인용 스타일 위반 | 서지 정보 일부 누락(저자가 원래 안 적었을 가능성) |
| 부호 사용 | em dash 등 검증 규칙 위반 | 따옴표 종류 비통일 |
| 문체 일관성 | 어미 혼용 (해라체+합쇼체) | 문장 길이 편차 큼 |

출력 끝에 공통 형식대로 점수와 `<!-- STAGE_COMPLETE: 04_review-proofreader -->` 마커.

## 2단계: 정합성 리뷰 (Coherence Checker)

### 역할
책 전체를 처음부터 끝까지 읽는 담당자. 여러 주에 걸쳐 쓰인 에세이가 하나의 책으로 읽히는지 확인한다.

### 입력 / 출력
- 입력: `{ACTIVE}/03_manuscript-v1.md`
- 출력: `{ACTIVE}/04_review-coherence.md`

### 평가 항목

| 항목 | 🔴 기준 | 🟡 기준 |
|------|---------|---------|
| 용어 불일치 | 같은 개념을 다른 용어로 지칭(book-config 용어 통일 목록 위반) | 용어 통일 목록에 없는 새로운 혼용 발견 (목록에 추가 제안) |
| 장 연결 | 장 사이 연결 문단 누락 | 연결 문단은 있으나 어색함 |
| 목차 일치 | book-config 목차 항목 누락 | 하위 절 1개 누락 |
| 중복 | 같은 논지가 두 장 이상에서 설명 없이 반복 | 인접 문단 표현 중복 |
| 순서 | 앞 장에서 참조하는 개념이 뒤 장에서 처음 나옴(순서 오류) | 순서는 맞으나 전개가 매끄럽지 않음 |

## 3단계: 학술 엄밀성 리뷰 (Academic Rigor Checker)

### 역할
같은 분야 학계 동료 심사자. "이 논지가 학위논문/학술지 심사를 통과할 수 있는가"를 본다. **새로운 근거를 만들어 채우라고 하지 않는다** — 근거가 없다는 사실 자체를 지적한다.

### 입력 / 출력
- 입력: `{ACTIVE}/03_manuscript-v1.md`
- 출력: `{ACTIVE}/04_review-rigor.md`

### 평가 항목

| 항목 | 🔴 기준 | 🟡 기준 |
|------|---------|---------|
| 인용 누락 | 통계·직접 인용에 출처 표기 자체가 없음(형식이 아니라 존재 여부) | 출처는 있으나 원전 확인이 어려운 2차 인용 |
| 논리 비약 | 전제와 결론 사이 단계가 누락되어 독자가 따라갈 수 없음 | 연결이 약하나 따라갈 수는 있음 |
| 자기모순 | 앞 장과 뒤 장의 주장이 명백히 충돌 | 미묘한 뉘앙스 차이 |
| 근거 없는 단정 | 데이터·선행연구 없이 단정한 핵심 주장 | 약한 근거를 둔 부차적 주장 |

이 리뷰어가 발견한 항목은 원칙적으로 전부 🟡 이상(제안)이다. 근거 자체를 새로 지어낼 수 없으므로 🔴로 분류해 "자동 반영"하지 않는다. 예외: 이미 원문 다른 곳에 있는 근거를 빠뜨리고 인용 안 한 경우(중복 서술 통합 실수)만 🔴로 자동 반영 가능.

## 4단계: 최소편집 준수 검수 (Minimal-Edit Compliance Checker)

### 역할
이 스킬의 핵심 안전장치. `{ACTIVE}/03_change-log.md`와 원본 에세이(`{ACTIVE}/01_essay-inventory.md`가 가리키는 파일들)를 대조하여, "자동 반영"으로 기록된 수정이 정말 기계적 교정 수준인지 검사한다.

### 입력 / 출력
- 입력: `{ACTIVE}/03_manuscript-v1.md` + `{ACTIVE}/03_change-log.md` + 원본 에세이 파일들
- 출력: `{ACTIVE}/04_review-minimal-edit.md`

### 검사 방법

1. 변경 로그의 "자동" 등급 항목을 하나씩 원문과 대조한다
2. 원문과 수정본의 의미가 달라졌다고 판단되면(문장 뜻이 바뀌었거나, 원문에 없던 내용이 추가되었거나, 원문의 뉘앙스나 강도가 달라졌으면) 🔴로 지적하고 "등급 재분류 필요"라고 명시한다
3. 연결 문단으로 표시된 부분에 원문에 없던 **새로운 주장이나 예시**가 섞여 있으면 🔴로 지적한다 (연결 문단은 순수하게 "이미 있는 논지를 잇는 다리"여야 한다)
4. 변경 로그에 기록되지 않은 수정(원문과 대조했을 때 다른데 로그에는 없는 부분)을 발견하면 **가장 심각한 🔴**로 지적한다 (추적 불가능한 수정이 있다는 뜻이므로)

### 평가 항목

| 항목 | 🔴 기준 | 🟡 기준 |
|------|---------|---------|
| 등급 오분류 | "자동"으로 표시됐지만 의미가 바뀐 수정 | 경계가 애매한 경우(재검토 권장) |
| 미기록 수정 | 변경 로그에 없는데 원문과 다른 부분 | (해당 없음 — 발견 즉시 🔴) |
| 연결 문단 오염 | 연결 문단에 새 주장/예시 혼입 | 연결 문단이 다소 김(내용 문제는 아님) |
| 원문 훼손 | 원문의 핵심 표현이나 저자 특유의 문체가 "개선"이라는 이유로 교체됨 | 문체가 살짝 다듬어졌으나 원 의미는 보존 |

### 출력 템플릿

반영 전 백업 (SKILL.md 백업 정책 1번 트리거).

🟡/🟢 전체 목록은 이 단계에서 `output/{ACTIVE}/pending-suggestions.md`로 모아 둔다 (실제 작성은 `/publish` 1단계에서 output 폴더가 확정된 뒤 채워도 되고, 여기서 초안을 만들어 둬도 된다).
