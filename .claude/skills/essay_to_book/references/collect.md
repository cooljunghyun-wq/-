# 에세이 수집 및 인벤토리

> 책쓰기 워크플로우 1단계. SKILL.md의 지시로 로드되는 실행 문서다.

**주의**: 이 단계는 웹 검색이나 새로운 자료 조사를 하지 않는다. 사용자가 이미 써 둔 에세이 파일을 빠짐없이 찾아 목록화하는 단계다.

## 시작 전 준비

`book/book-config.md`를 읽고 다음을 파악한다:
- 에세이 원본 폴더 위치, 파일명 규칙
- 목차 뼈대 (몇 개 부/장으로 나뉘는지 대략적인 그림)

## 활성 폴더 결정 (이 단계만 새로 만든다)

이 단계는 **새로운 프로젝트의 시작**이므로 항상 새 활성 폴더를 만든다.

```bash
TODAY=$(date +%Y%m%d)
BASE="draft/${TODAY}"
ACTIVE="${BASE}"
SUFFIX=1
while [ -d "${ACTIVE}" ]; do
  ACTIVE="${BASE}_$(printf '%02d' ${SUFFIX})"
  SUFFIX=$((SUFFIX+1))
done
mkdir -p "${ACTIVE}"
mkdir -p "output/${ACTIVE#draft/}"
echo "활성 프로젝트 폴더: ${ACTIVE}"
```

## 원본 탐색

`book/book-config.md`의 "원본 위치"에 적힌 경로를 먼저 확인한다. 없거나 비어 있으면 SKILL.md에 정의된 기본 탐색 순서(`essays/`, `원고/에세이/`, `에세이/`)를 확인한다.

찾은 폴더 안의 모든 `.md`, `.txt`, `.docx` 파일을 후보로 삼는다. `.hwp` 파일이 섞여 있으면 목록에는 올리되, 상태를 "변환 필요"로 표시하고 사용자에게 `.docx`나 `.txt`로 바꿔 달라고 안내한다.

원본을 하나도 찾지 못하면 다음 단계로 넘어가지 않고 사용자에게 정확한 경로를 묻는다.

## 인벤토리 작성

찾은 각 에세이 파일에 대해 다음을 추출한다:

- 파일 경로
- 작성일 (파일명에 날짜가 있으면 그것을, 없으면 파일 내부에 날짜 표기가 있는지 확인, 둘 다 없으면 파일 수정 시각을 참고용으로 표기하고 "추정"이라고 밝힌다)
- 제출 강좌/세미나명 (에세이 안에 표기되어 있으면 추출, 없으면 공란)
- 원제목 (에세이 자체의 제목. 없으면 첫 문장이나 파일명에서 유추하고 "(유추)"라고 밝힌다)
- 분량 (글자 수, 공백 제외)
- 핵심 주장 한 줄 요약 (**절대 새로 쓰지 않는다** — 에세이 본문에서 논지를 담은 문장을 그대로 뽑아 인용하거나, 요약이 불가피하면 "요약(AI 작성, 원문 아님)"이라고 명시한다)
- 이미 있는 인용/각주 개수 (있으면 표시. 인용 스타일 통일 작업량을 가늠하는 용도)

## 출력 규칙

`draft/{ACTIVE}/01_essay-inventory.md`에 다음 형식으로 저장한다.

```markdown
# 01. 에세이 인벤토리

| # | 파일 | 작성일 | 강좌/세미나 | 원제목 | 분량(자) | 핵심 주장(원문 발췌) | 기존 인용 수 |
|---|------|--------|-------------|--------|----------|----------------------|--------------|
| 1 | essays/20260302_행위자성.md | 2026-03-02 | 정치철학 세미나 | 행위자성과 구조 | 3,200 | "..." | 4 |
| 2 | ... | | | | | | |

## 특이사항
- (변환 필요, 작성일 추정, 미완성으로 보이는 파일 등을 여기에 기록)

## 누락 확인
- 총 N개 파일 발견. 사용자가 기억하는 에세이 개수와 일치하는지 아래 질문으로 확인한다.
```

인벤토리 작성 후, 사용자에게 발견한 총 개수를 한 줄로 보고하고 "이 개수가 맞는지" 확인을 요청한다 (기억에 없던 파일이 빠졌을 수 있으므로).

## 완료 처리

인벤토리가 완성되고 사용자가 개수를 확인해 주면 파일 마지막 줄에 상태 마커를 남긴다:

```
<!-- STAGE_COMPLETE: 01_essay-inventory -->
```

완료 후 사용자에게 한 줄로 안내한다:
```
인벤토리 완료 (N개 에세이). /organize로 목차 설계를 시작하세요.
```
